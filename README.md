# 🌄 Scenic View Sidebar

A modern and responsive **sidebar navigation UI** built using **HTML and CSS**.
This project features a smooth sliding sidebar, glassmorphism effect, hover animations, social media icons, and a scenic background image.

## ✨ Features

* 📱 Responsive sidebar design
* 🍔 Hamburger menu
* ❌ Close button
* 🪟 Glassmorphism / blur effect
* 🎨 Smooth hover animations
* 🔵 Active menu item
* 📸 Scenic background image
* 🔗 Social media icons
* ✨ Modern UI design
* 💻 Pure HTML & CSS

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts (Poppins)

## 🚀 How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
